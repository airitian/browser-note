配置后内容会异步同步到七牛云对象存储；不配置则仅本地保存。

打开方式：浏览器右上角扩展图标 → 右键 →「选项」。

GitHub 全量备份（第三副本）

把笔记 Markdown（含元数据）+ 原图全量镜像到你的 GitHub 私有仓库，历史靠 git 提交追溯。仅「立即全量备份」手动触发，以及每天首次打开笔记且七牛拉取成功后自动跑一次（内容无差异不产生提交）。只推不拉、明文存储，本期不提供导入工具。

实时同步通道

七牛 CDN 对同一路径缓存 1 年且覆盖写不会让缓存失效，因此每次推送会额外写一份全新文件名的全量快照（CDN 从未缓存 → 必然回源）。另一台浏览器拉取时先找这份快照，从而拿到刚推送的内容；通道不可用时自动回退到普通索引通道（可能延迟数分钟）。

数据回退

每小时自动在云端保存一份全量快照（保留 7 天可选）。回退会把笔记恢复到所选时间点的状态；当前数据会先自动存为快照，可随时再回退回来。新建快照后列表可能有几分钟延迟（云端 CDN 缓存），重开本页即可。
